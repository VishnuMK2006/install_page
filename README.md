# Redefine Arcade Games Portal

Welcome to the Redefine Arcade Games Portal! This project is a static web mockup designed to simulate a game download platform. It showcases download pages for popular titles with a modern, responsive design.

The portal features download pages for the following popular titles:

- **Apex Legends**: `install_page/apex.html`
- **Call of Duty**: `install_page/cod.html`
- **PUBG**: `install_page/pubg.html`
- **Valorant**: `install_page/valorent.html`
- **Free Fire**: `install_page/freefire.html`

## 🛠️ Technologies Used

- **HTML5**: For structure and content.
- **CSS3**: For styling and layout (responsive design).
